# FinTrack AI 💸

**Understand your spending. Manage your budget. Make smarter financial decisions.**

FinTrack AI is a personal finance dashboard built with React and Vite that helps users record income and expenses, review spending patterns, monitor financial activity, and explore practical financial insights through a clean interface.

The application runs primarily in the browser and uses local JavaScript logic and `localStorage` to manage financial data and preferences. It is a frontend demonstration project, not a connected banking or production financial service.

**Live Demo:** https://fintrackai-g9-fee-project.vercel.app/  
**Repository:** https://github.com/SAHAJCSE/FintrackAi

---

## Features

## Features

- **Expense tracking:** Add income and expenses by category and date. Transactions are stored in browser `localStorage`.
- **Dashboard:** Review balances, income, expenses, spending categories, financial health scores, and recent transactions.
- **Receipt scanner:** Upload and preview receipt images, then review and edit example transaction details. Receipt scanning is simulated; no actual OCR is performed.
- **Budget management:** Review spending totals and category-wise expense breakdowns based on recorded transactions.
- **Financial health score:** View a simplified indicator of your financial health based on the application's available financial data.
- **Financial insights:** Explore spending suggestions generated by local JavaScript rules and transaction data, without using an external AI model.
- **AI finance coach:** Interact with a built-in coach that provides predefined, rule-based financial tips and budgeting suggestions.
- **Activity calendar:** View transaction activity by date and record expenses for a selected day.
- **Smart commands:** Use supported text commands to navigate dashboard sections or prepare an expense for confirmation. Commands are processed locally without a language model.
- **Transaction history:** Review recent income and expense records in one place.
- **Budget overview:** Monitor spending patterns and identify categories that may need attention. This is not a predictive forecasting or configurable budget-alert system.
- **Additional financial views:** Explore demo content for bill reminders, subscriptions, and investment suggestions.
- **Languages:** Switch the interface between English, Hindi, and Punjabi. Some screens or content may remain in English.
- **Themes:** Switch between light and dark modes, with theme preferences saved in browser `localStorage`.
- **Local data persistence:** Keep supported transactions and preferences saved in the current browser. Data is not synchronized across devices.
- **Responsive interface:** Access the dashboard and its financial tools through a user-friendly interface designed for different screen sizes.

## 🚀 Getting Started

Follow these steps to run FinTrack AI locally.

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your system.
- npm, which is included with Node.js.
- Git installed to clone the repository.

### 1. Clone the repository

```bash
git clone https://github.com/SAHAJCSE/FintrackAi.git
```

### 2. Open the project directory

```bash
cd FintrackAi
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### 5. Create a production build

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

## 💾 Data Storage

FinTrack AI uses browser `localStorage` to persist supported transaction data and user preferences.

- Data is stored locally in the current browser.
- Data is not automatically synchronized across devices.
- Clearing browser storage may remove saved application data.
- A first visit may display example transactions.
- Demo sign-in and sign-up flows do not create real user accounts.

For these reasons, the application should be used with non-sensitive demonstration data.

---

## ⚠️ Limitations

FinTrack AI is currently a frontend demonstration project.

- **No bank integration:** Transactions must be entered through the application.
- **No real authentication:** Sign-in and sign-up are client-side demonstration flows.
- **No real AI service:** Financial coach responses and smart commands use local JavaScript logic.
- **No automatic receipt OCR:** Receipt scanning uses a simulated workflow.
- **Limited forecasting:** Spending indicators do not guarantee future financial outcomes.
- **Demo financial content:** Some reminders, subscriptions, and investment suggestions may use sample data.
- **No server-side database:** Financial data is not stored on a remote server.

FinTrack AI is intended for learning, demonstration, and personal finance interface exploration. It is not a substitute for professional financial advice.

---

## 🔒 Privacy & Security

The current application stores supported data in the browser rather than a dedicated backend.

Do not enter banking passwords, payment credentials, or other sensitive financial information. Browser storage is not equivalent to encrypted server-side financial storage, and the application does not currently provide bank-grade security guarantees.
